# User Story

| Story ID | User Story |
|----------|------------|
| US-1     | As a guest, i want to create a checklist without logging in, so that i can try the product. |
| US-2     | As a guest (or user), i want to edit my existing checklist, so that i can modify my plan. |
| US-3     | As a guest (or user), i want to view a checklist i created earlier. |
| US-4     | As a guest (or user), i want to manage the items (check) in a checklist: add, update, toggle, delete. |
| US-5     | As a user, i want to sign up with email, so that i can save my data across sessions. |
| US-6     | As a user, i want to sign in, so i can access my save checklists. |
| US-7     | As a user, i want to sign out safely to protect my data. |
| US-8     | As a signed-in user, i want my guest checklist to be merged or preserved when i login. |
